Ultraviolet One-Click Generator

This generator downloads the exact UV files currently stored in the DarkSyr/ISFILES repository and writes a complete same-origin UV deployment into a folder you choose.

The generated site contains the UV bundle, handler, configuration, service worker, root service worker, and a browser UI. The generated site still needs a working Bare server because UV itself does not provide the network transport.

Ready.

Use Chrome/Edge on HTTPS or localhost. File System Access is required.
