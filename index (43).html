Bare server

Default is https://incog.dev/bare/. If proxying fails, set a working Bare endpoint and click Save. This static build does not include a Bare server — only the UV client.

How to host (one public link)

Upload this whole folder to any static host (GitHub Pages, Netlify, Cloudflare Pages, nginx, etc.) so these files are reachable on the same origin:

index.html · sw.js · uv.bundle.js · uv.config.js · uv.handler.js · uv.sw.js

Open the site over https:// (or localhost). Service workers will not register from data:, blob:, or file://.
